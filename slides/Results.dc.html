Metrics: hit@k because #1 is what the user and the answer step actually see. MRR because it rewards moving the right page upward. Same questions, same 50 candidates before and after. Only the order changes.
How it was kept honest
Weights chosen on 250 questions, reported once on 250 held-out ones. Ship rule for every idea: held-out #1 or MRR up, top-5 not down. One of two failed it.
In the backend
An optional step in the engine's search, turned on in the local demo. Off restores the original exactly. No API key needed. 28 unit tests, plus a check that the live API returns the offline ranking.
Honest limits
The QA file also trained the retriever, so absolute numbers are optimistic. The split guards against tuning, not familiarity. The title weight relies on good titles.
